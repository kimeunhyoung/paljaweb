네임코드 · 이름 수비학

가이드 · 이름

이름에도 수비학 에너지가 있습니다. 네임코드는 한글·영문 이름에서 운명수·혼의수·성격수를 계산하고, 후보 이름을 최대 5개까지 비교합니다.

세 가지 이름 수

운명수 (Expression / Destiny)

이름 전체 글자의 수비학 값을 합친 수. 타고난 재능·세상에 보여 주고 싶은 역할.

혼의수 (Soul Urge)

이름 중 모음에 해당하는 글자만 합산. 속마음·진짜 동기.

성격수 (Personality)

이름 중 자음에 해당하는 글자만 합산. 첫인상·겉으로 드러나는 성격.

한글 이름 계산

팔자연구소는 피타고라스식으로 한글 이름 각 글자에 1~9 값을 부여해 합산합니다. 자음·모음 구분은 한글 음절 구조에 맞게 처리합니다.

개명·예명·아이 이름 후보를 넣어 숫자 패턴이 어떻게 바뀌는지 비교할 수 있습니다.

이름을 고를 때 참고할 점

  • 운명수만 보지 말고 혼의수·성격수가 조화하는지 볼 것
  • 인생여정수(생일)와 운명수가 너무 충돌하면 삶에서 긴장감이 클 수 있음 — 반드시 나쁜 것은 아님
  • 발음·의미·가족 의견·법적 절차가 수비학보다 우선인 경우가 많음

라이프코드와 함께

라이프코드에서 생년월일+이름을 함께 넣으면 통합 스토리와 완성수까지 볼 수 있습니다. 이름만 집중 비교는 네임코드가 편합니다.
